# Row Ready

Know Before You Row.

Row Ready is a rowing companion app that combines weather, river conditions, club information and community reports to help rowers make safer and smarter decisions before going on the water.

## Current Status

🚧 MVP Development — UI prototype and core infrastructure in place

## Technologies

- FlutterFlow
- Firebase
- Cloud Firestore
- Open-Meteo
- Environment Agency API
