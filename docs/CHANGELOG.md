## v0.2.0 — UI Prototype

### Added

- Splash screen
- Today page UI
  - Selected club / location
  - "GO ROW" recommendation card
  - Best rowing window
  - Confidence indicator
  - Last updated timestamp
  - Summary of wind, gusts, water level and rain conditions
  - Detailed condition cards
  - "Why is it a Go?" explanation
- Boats page UI
  - Available boats section
  - Unavailable boats section
  - Boat cards
  - Boat name/type/location/status
  - Add boat button
- Locations page UI
  - Location cards
  - Club and status information
  - Add location button
- Profile page UI
  - Personal information
  - Club information
  - Preferences
- Page navigation and transitions
- Initial app-wide visual design system

### Design decisions

- 24 px page padding
- 16 px card padding
- 16 px card corner radius
- Secondary Background for cards
- Primary text in black
- Success colour for positive/available status
- Consistent card-based layout
- Splash screen transitions to Today with a fade
- Today provides both an overall recommendation and the underlying conditions/explanation

### Future improvements identified

- Club-specific favourite boats
- Club boats / Favourite boats toggle
- Private user boat notes/reviews
- Boat equipment and blade information
- More detailed locations
- Location favourites
